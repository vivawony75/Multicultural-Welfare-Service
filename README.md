# 다문화 복지 브릿지 (다문화 대상자 복지 서비스 신청 웹 앱)

바탕화면의 `[복지서비스]` 폴더에 생성된 **다문화 대상자 맞춤형 복지 지원 신청 윈도형(Window-type) 웹 애플리케이션**입니다.

---

## 1. 주요 기능 요약

1. **윈도형(Window-type) 상단 메뉴 전환 및 접근 권한 분리**
   - 상단 메뉴 클릭 시 스크롤 이동 대신 해당 메뉴의 전용 윈도 창으로 즉시 전환됩니다.
   - **[사이트 안내]**: 로그인하지 않아도 **모두에게 공개** (`안녕하세요? (상세 내용은 제작 후에 다시 수정해서 업로드)` 문구 포함)
   - **[서비스 신청]**: **회원 가입 및 로그인한 회원에게만 공개** (비로그인 시 잠금 안내 카드 표시)
   - **[관리자 메뉴]**: **관리자(`admin` / `1234`)에게만 공개**
   - **[회원가입]**: 신규 다문화 회원 가입 전용 윈도

2. **[서비스 신청] 메뉴 (중복 체크 가능)**
   - **한국어 교육**: 초급, 중급, 고급 (체크박스)
   - **의료 지원**: 의료 지원 신청 (체크박스)
   - **법률 상담**: 법률 상담, 심리 상담 (체크박스)
   - **기타**: 체크 및 직접 입력 가능
   - **희망 날짜**: 직접 입력 (달력 선택 보조 기능 포함)
   - **부탁하고 싶은 말**: 직접 입력

3. **[회원가입] 및 계정 규칙**
   - **관리자 계정**: 아이디 `admin`, 비밀번호 `1234`
   - **일반 회원**: 아이디, 이름, **비밀번호 숫자 8자리**(`0~9` 8자리 필수 검증)
   - **필수 입력 10개 항목**:
     1. **사용하는 언어 (복수 체크 가능)**: `영어`, `중국어`, `일본어`, `몽골어`, `러시아어`, `인도네시아어`, `네팔어`, `미얀마어`, `캄보디아어`, `필리핀어`, `베트남어`, `우즈베키스탄어`, `기타(직접 입력)`
     2. **국적**
     3. **한국어 사용 가능 여부**: `익숙함`, `보통`, `잘 못함`, `전혀 못함` 체크
     4. **체류자격**: 일반 체류자격 입력 + 해당없는 사람은 `미등록`, `체류자격 상실` 체크
     5. **종교**: `기독교`, `천주교`, `불교`, `힌두교`, `이슬람교`, `기타` 체크
     6. **연락처**
     7. **거주 지역**: `부산`, `김해`, `양산`, `기타(직접 입력)` 체크
     8. **나이**
     9. **직업**
     10. **가족(동거인)**

4. **[관리자 메뉴] 하위메뉴 및 WORD 파일 다운로드**
   - **하위메뉴 1 (회원 가입 작성 내용)**: 전체 회원 목록 및 상세 작성 내용 조회 + **개별/전체 MS WORD(`.doc`) 파일 다운로드**
   - **하위메뉴 2 (서비스 신청 내용)**: 전체 서비스 신청 내역 조회 + **개별/전체 MS WORD(`.doc`) 파일 다운로드**

---

## 2. 실행 방법

바탕화면 `[복지서비스]` 폴더 안의 `index.html` 파일을 더블클릭하여 브라우저에서 바로 실행하거나, 로컬 서버(`npx serve .` 또는 VS Code Live Server)로 열 수 있습니다.
